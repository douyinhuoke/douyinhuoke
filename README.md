## 这家公司在做什么

用 AI + 零售行业知识 + 抖音运营，帮中小超市把线上客流做起来。

超市缺客流，尤其缺年轻客流；但超市毛利普遍 15 个点、净利 5–8 个点，掏不出传统代运营的钱（成本大头在上门拍摄和驻场直播）。我们的做法是**不去门店**：把选题、脚本、话术、商品图、上架、平台资源提报做好，门店按清单自己拍，微信群远程交付——所以全国各地级市、县级市都能合作。

第一步不是拍视频，是先把货盘理顺。顺序坚持：短视频 → 直播 → 适量投流。

## 团队

核心成员此前在超市收银软件厂商**思迅软件**工作十年以上，积累近 **8000 家**超市客户资源（团队客户资源总量，非本公司服务门店数）；**2026 年**公司成立后转向超市抖音代运营，已与其中 **100 家**达成合作，门店集中在江苏、安徽等地。思迅软件与本公司无股权、无授权、无代理关系。
